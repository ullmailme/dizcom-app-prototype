# DizCom APP: прототип экранов

Кликабельный прототип приложения для компьютерного сервиса. Это только вид: справочник клиентов (устройства, пароли, файлы), задачи со сметами, подрядчики и помощник. **Все данные выдуманные**, настоящих клиентов и паролей здесь нет.

**Открыть прототип:** https://ullmailme.github.io/dizcom-app-prototype/

## Как смотреть

- На входе подойдёт любой код из четырёх цифр или кнопка отпечатка.
- Раздел «Ещё», блок «Как смотреть прототип»: можно зайти как руководитель, сотрудник или подрядчик. Подрядчик видит только свои задачи и то, что по ним выдано.
- Там же выключатель «Связь с сервером» показывает работу без интернета: правки копятся и уходят на сервер, когда связь вернулась.
- Поиск на главной ищет по всем данным сразу, например «альфа wifi» или «192.168.1.13».
- Работает на телефоне и на компьютере, есть светлая и тёмная тема.

## Что пока не работает

- Кнопки «добавить» и «редактировать» только показывают подсказку.
- Данные хранятся в памяти страницы, после перезагрузки всё возвращается как было.
- Нет сервера, настоящего входа и шифрования. Это следующие этапы.

## Для разработчиков

Исходники лежат в `src/`, готовая страница собирается одной командой:

```
node build.js
```

Библиотек нет, это обычные HTML, CSS и JavaScript.
